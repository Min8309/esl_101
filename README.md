# 말줍 · 나만의 표현 수집함

> 좋아하는 한마디를 주워, 내 말로.

**말줍**은 ‘마음에 드는 말을 줍다’라는 뜻을 담았습니다.

좋아하는 영상의 표현을 골라 저장하고, 따라 말하며, 다음 3일 동안 복습하는 1인 개발용 웹앱 시제품입니다. 기본 카드·메모·복습은 프레임워크나 외부 패키지 설치 없이 실행합니다. 유튜브 주소로 자막을 가져오려면 아래의 Python 자막 도구 설치가 추가로 필요합니다.

## 실행

Node.js 20 이상에서:

```sh
npm start
```

브라우저에서 http://localhost:3000 을 여세요. 다른 포트는 `PORT=8080 npm start`로 지정합니다. 파일을 더블 클릭하는 file:// 실행 대신 HTTP 서버를 사용하세요. 모바일 등 다른 기기의 마이크 녹음에는 HTTPS 호스팅이 필요합니다.

## 구현 기능

- 표현·뜻·학습 메모·유튜브 링크·시작 시간·출처를 저장하고 수정
- SRT/VTT 자막 불러오기 → 문장 선택 → 카드 저장
- 유튜브 공식 임베드 플레이어로 지정한 시간부터 영상 재생
- 카드 검색, 개별 삭제, 선택 삭제
- 카드 삭제 시 연결된 녹음 삭제 또는 보관 선택
- MediaRecorder 녹음 → 미리 듣기 → 명시적 저장, 개별 재생·삭제·다운로드
- 첫 학습 다음 날부터 3회 복습, 날짜별 중복 완료 방지, 빈칸 퀴즈
- 카드·복습·녹음을 포함한 전체 JSON 백업과 복원
- 전체 데이터 삭제
- 모바일 대응 한국어 UI

데이터는 IndexedDB에 보관합니다. 최초에는 비어 있으며 사용자 자료를 임의로 생성하지 않습니다. 기기와 브라우저, 사이트 주소가 달라지면 저장 데이터도 분리됩니다. 브라우저 데이터를 삭제하면 자료를 잃을 수 있으니 백업하세요. 녹음은 마이크 권한과 MediaRecorder를 지원하는 브라우저가 필요합니다. 녹음 데이터는 서버로 전송하지 않습니다. 유튜브 플레이어와 Google Fonts는 외부 네트워크를 사용합니다.

## 사용 순서

1. 표현 추가로 직접 문장을 입력하거나 내 표현 수집함 → 자막 불러오기에서 이용 권한이 있는 파일을 선택합니다.
2. 뜻과 문맥 메모를 작성합니다. 필요하면 유튜브 링크와 시작 시간을 입력합니다.
3. 저장된 카드를 열고 녹음 시작 → 종료 → 미리 듣기 → 녹음 저장을 누릅니다.
4. 다음 날 오늘의 복습에서 빈칸 퀴즈를 확인하고 복습 완료를 누릅니다.
5. 데이터 관리에서 전체 백업하거나 녹음 보관함에서 파일을 개별 다운로드합니다.

## 시제품 범위

AI 해설 API, 음성 인식 비교, 정밀 발음 평가, 푸시 알림, 계정·서버 동기화, 자막 없는 영상의 음성 받아쓰기는 구현하지 않았습니다. 학습 메모는 사용자가 작성합니다. 카드의 전체 문장은 언제든 확인할 수 있으며 퀴즈는 자기 확인 방식입니다. 오답이어도 정답 확인 후 복습을 완료할 수 있습니다. 3일 복습 완료는 숙련도를 보장하지 않습니다.

영상의 임베드 허용 여부에 따라 재생이 제한될 수 있습니다. 영상·음성 파일은 다운로드하지 않으며, 주소로 자막 불러오기를 요청하면 공개 자막 텍스트만 가져옵니다. 자막·표현 이용 권한은 사용자가 확보해야 합니다.

## 검증

```sh
npm run check
npm test
```

날짜 경계, 복습 중복 방지와 완료, 유튜브 URL 검증, SRT/VTT 파싱을 테스트합니다. 실제 기기에서 마이크 권한·녹음·저장 후 새로고침·백업 복원·카드와 녹음 삭제를 추가 확인해야 합니다.

## 구조

- `index.html`: 앱 레이아웃 및 편집 다이얼로그
- `src/style.css`: 반응형 화면
- `src/app.js`: IndexedDB, 카드·녹음·백업과 화면 흐름
- `src/core.js`: 날짜·복습·자막·URL 순수 함수
- `server.mjs`: 의존성 없는 로컬 정적 서버
- `tests/core.test.js`: 핵심 로직 테스트

## 배포

HTML/CSS/JavaScript 정적 앱이므로 GitHub Pages에서도 실행 가능합니다. 저장소 Settings → Pages → Deploy from a branch → main / root를 선택하면 됩니다. 최초 공개 여부 및 Pages 사용 가능 여부는 저장소 설정과 요금제에 따릅니다. 사이트 원본이 공개되더라도 학습 데이터는 해당 브라우저에만 저장됩니다. 이 작업에서 Pages 활성화나 공개 배포는 하지 않았습니다.


## 학습 달력과 암기 체크리스트

- 학습 달력에서 월 이동, 오늘 이동, 날짜별 첫 학습·복습 완료·복습 예정·밀린 복습을 확인하고 문장을 엽니다.
- 복습 완료 시 실제 날짜를 카드에 기록합니다. 이전 버전에서 완료한 복습 날짜는 추측해 생성하지 않습니다.
- 남은 복습은 하루 간격으로 예상 표시하며, 연체된 첫 복습은 오늘에 표시합니다. 완료하면 이후 예상 일정이 조정됩니다.
- 표현 추가/수정 또는 카드 상세에서 ‘꼭 외울 문장’을 선택해 암기 체크리스트에 담습니다.
- 체크리스트에서 암기 여부를 체크하거나 해제합니다. 암기 체크는 3일 복습 횟수를 변경하지 않습니다.
- 카드 상세에서 날짜가 붙는 암기 메모를 여러 개 기록하고 개별 삭제합니다. 체크리스트에서 최근 메모를 볼 수 있습니다.
- 목록에서 빼기는 카드나 메모를 삭제하지 않습니다. 카드 삭제 시 해당 카드의 암기 상태·메모·복습 날짜도 함께 삭제합니다.
- 새 필드는 기존 cards 저장소에 보관하므로 기존 데이터와 백업 형식을 유지하며, 전체 백업·복원에 포함됩니다.

## Google Sheets에 메모 저장

데이터 관리 → Google Sheets에서 현재 카드 전체를 **새 스프레드시트**로 저장합니다. 표현, 뜻, 학습 메모, 날짜별 암기 메모, 영상 링크·시작 시간·출처, 복습·암기 상태를 포함합니다. 녹음은 제외됩니다. 저장할 때마다 새 파일을 만들며 기존 시트를 덮어쓰지 않습니다. 시트의 편집 내용을 앱으로 가져오는 기능이나 자동·양방향 동기화는 제공하지 않습니다. 앱의 원본 자료는 계속 IndexedDB에 저장됩니다.

최초 연결 설정:

1. Google Cloud Console에서 프로젝트를 선택하고 **Google Sheets API**를 사용 설정합니다.
2. Google Auth Platform에서 동의 화면을 설정합니다. 테스트 모드이면 사용할 Google 계정을 테스트 사용자로 추가합니다. 요청 범위는 `https://www.googleapis.com/auth/drive.file`입니다. 앱을 통해 생성한 파일에 대한 접근에 사용합니다.
3. OAuth 클라이언트를 **웹 애플리케이션** 유형으로 생성합니다. 승인된 JavaScript 원본에 앱의 실제 원본(스킴·호스트·포트)을 등록합니다. 로컬 개발 기본값은 `http://localhost:3000`입니다. 배포 시 해당 HTTPS 원본을 추가합니다. 경로는 넣지 않습니다. 이 토큰 흐름에는 리디렉션 URI나 클라이언트 보안 비밀이 필요하지 않습니다.
4. 앱 데이터 관리에 클라이언트 ID(`…apps.googleusercontent.com`)를 입력하고 **Google 연결 준비 → Google 계정 연결**을 누릅니다. 팝업과 파일 접근 권한을 허용합니다.
5. **메모를 새 시트에 저장**을 누르고 완료 메시지와 생성된 시트 링크를 확인합니다.

클라이언트 ID는 비밀이 아니며 이 브라우저의 localStorage에 보관됩니다. 액세스 토큰은 메모리에만 보관하고 앱의 백업이나 저장소에는 기록하지 않습니다. 새로고침하거나 인증이 만료되면 다시 연결하세요. 연결 해제는 토큰 권한을 해제하며 이미 생성한 시트를 삭제하지 않습니다. 메모는 저장 버튼을 눌렀을 때 Google로 전송되며 파일은 자동으로 공개 공유되지 않습니다. 전송 도중 실패하면 빈 파일이 남을 수 있으며 안내된 링크로 확인할 수 있습니다.

필요한 Google 연결 대상은 `accounts.google.com`(로그인 도구), `sheets.googleapis.com`(Sheets API), `docs.google.com`(시트 열기)입니다. Google 로그인 화면은 추가 Google 인증 도메인을 사용할 수 있습니다. 네트워크 제한이 있다면 실제 로그인 흐름에 맞춰 허용하세요.

검증: `npm run check`, `node --check src/google-sheets.js`, `npm test`. 테스트는 데이터 변환, 수식 대신 일반 문자열 저장, API 호출 구조와 실패 처리를 모의 응답으로 확인합니다. 실제 Google 로그인·시트 생성은 본인의 클라이언트 ID와 브라우저에서 별도 확인해야 합니다.


## 유튜브 주소로 자막 불러오기

이 기능에는 Node.js 22 이상 서버와 Python 3.10 이상이 필요합니다. **최초 한 번**, 저장소 폴더에서 다음을 실행합니다. Windows의 Anaconda 프롬프트에서도 사용할 수 있습니다.

```sh
npm run setup:youtube
npm start
```

`python` 명령이 없다면 Python을 설치하고 PATH에 추가하세요. Linux/macOS에서 `python3`만 있는 경우 `python3 -m pip install -r requirements-youtube.txt`를 실행합니다. 가상환경 사용을 권장합니다. 서버는 Windows에서 `python`, Linux/macOS에서 `python3`를 실행하며, 다른 인터프리터는 서버 실행 시 `PYTHON_BIN` 환경 변수에 실행 파일 경로로 지정할 수 있습니다.

1. 메인 **학습 대시보드**의 **영상 속 표현을 스크립트로 만나보세요**에서 주소를 입력합니다. 내 표현 수집함 → **유튜브 자막 불러오기**에서도 같은 기능을 사용할 수 있습니다.
2. 영상 주소를 붙여넣고 영어·한국어·일본어 중 자막 언어를 선택합니다.
3. **자막 가져오기**를 누르면 해당 언어의 공개 수동 자막을 우선 가져옵니다. 없으면 자동 자막을 사용합니다. 다른 언어로 자동 번역하지는 않습니다.
4. 메인 화면의 주소 입력칸 아래에 시간별 스크립트 목록이 나타납니다. 자막을 검색하고 **문장 저장**을 누릅니다. 시간 링크는 영상의 해당 장면을 엽니다. 카드 편집창에 문장, 영상 링크, 시작 시간, 영상 제목이 채워집니다. 메모를 작성하고 저장하세요.

영상·음성 파일을 다운로드하거나 AI 음성 인식을 수행하지 않습니다. 자막이 없거나 비공개·연령·지역 제한, 로그인 요구, YouTube의 접근 차단이 있으면 가져오지 못할 수 있습니다. 유튜브는 자막 접근 방식을 변경할 수 있으므로 문제가 지속되면 자막 도구 업데이트 여부를 확인하세요. 우회나 쿠키 수집은 하지 않습니다. SRT·VTT 파일 불러오기도 계속 사용할 수 있습니다.

이 기능은 `/api/youtube-transcript`를 제공하는 `npm start` 서버에서만 동작하며 GitHub Pages 같은 정적 호스팅에서는 사용할 수 없습니다. PC의 인터넷 연결에 YouTube 접근이 허용되어야 합니다. 클라우드의 제한된 네트워크에서는 `www.youtube.com`, `youtube.com` 및 반환되는 자막 URL의 YouTube 도메인 접근이 별도로 필요할 수 있습니다.

자막 도구 테스트: `python -m unittest discover -s tests -p "test_*.py"`. Node API와 카드 로직 테스트는 `npm test`로 실행합니다. 모의 응답 테스트 통과만으로 실제 영상 접근 성공을 보장하지 않습니다.

불러온 스크립트와 형광펜 기록은 이 브라우저의 IndexedDB에 저장되어 새로고침해도 유지됩니다. ‘보관한 스크립트’에서 이전 영상을 다시 열 수 있습니다. 기기 간 자동 동기화는 아니며, 중요한 기록은 전체 백업을 내려받으세요.


## 스크립트 형광펜과 드래그 수집

- 메인 화면의 스크립트는 시간과 문장이 이어지는 읽기 형식입니다. 시간 링크는 영상의 해당 위치를 엽니다.
- 형광펜 색상을 고른 뒤 단어 또는 여러 줄의 문장을 드래그해 선택하면 자동으로 표시합니다. 터치 기기에서는 텍스트를 선택하고 **선택 영역 표시**를 누를 수 있습니다.
- 기본 분류는 노랑 **단어**, 초록 **문장**, 파랑 **표현**, 분홍 **질문**, 보라 **문법**입니다. **색상별 수집 카테고리 설정**에서 24자 이내로 바꿀 수 있습니다. 새 분류명은 이후 수집한 카드에 적용하며 이미 수집한 카드의 카테고리는 카드 편집에서 바꿉니다.
- **형광펜 기록**에는 선택한 부분만 저장됩니다. 색상으로 필터한 다음 **표시한 내용만 수집**을 누르면 그 색상의 기록만 카드로 저장합니다. 전체 색상 보기에서는 모든 기록을 수집합니다. 표시 삭제는 형광펜만 지우며 이미 수집한 카드는 유지합니다.
- 선택된 텍스트를 다시 잡아 오른쪽 **내 표현 수집함에 바로 넣기** 영역으로 끌어놓으면 편집창 없이 즉시 저장합니다. 형광펜 기록의 텍스트도 끌어놓을 수 있습니다. 터치·키보드에서는 **선택 내용 수집** 또는 개별 **수집** 버튼을 사용하세요.
