# 말줍 · 나만의 표현 수집함

> 좋아하는 한마디를 주워, 내 말로.

**말줍**은 ‘마음에 드는 말을 줍다’라는 뜻을 담았습니다.

좋아하는 영상의 표현을 골라 저장하고, 따라 말하며, 다음 3일 동안 복습하는 1인 개발용 웹앱 시제품입니다. 프레임워크나 외부 패키지 설치 없이 실행합니다.

## 실행

Node.js 20 이상에서:

```sh
npm start
```

브라우저에서 http://localhost:3000 을 여세요. 다른 포트는 `PORT=8080 npm start`로 지정합니다. 파일을 더블 클릭하는 file:// 실행 대신 HTTP 서버를 사용하세요. 모바일 등 다른 기기의 마이크 녹음에는 HTTPS 호스팅이 필요합니다.

## 구현 기능

- 표현·뜻·학습 메모·유튜브 링크·시작 시간·출처를 저장하고 수정
- SRT/VTT 자막 불러오기 → 문장 선택 → 카드 저장
- 유튜브 공식 임베드 플레이어로 지정한 시간부터 영상 재생
- 카드 검색, 개별 삭제, 선택 삭제
- 카드 삭제 시 연결된 녹음 삭제 또는 보관 선택
- MediaRecorder 녹음 → 미리 듣기 → 명시적 저장, 개별 재생·삭제·다운로드
- 첫 학습 다음 날부터 3회 복습, 날짜별 중복 완료 방지, 빈칸 퀴즈
- 카드·복습·녹음을 포함한 전체 JSON 백업과 복원
- 전체 데이터 삭제
- 모바일 대응 한국어 UI

데이터는 IndexedDB에 보관합니다. 최초에는 비어 있으며 사용자 자료를 임의로 생성하지 않습니다. 기기와 브라우저, 사이트 주소가 달라지면 저장 데이터도 분리됩니다. 브라우저 데이터를 삭제하면 자료를 잃을 수 있으니 백업하세요. 녹음은 마이크 권한과 MediaRecorder를 지원하는 브라우저가 필요합니다. 녹음 데이터는 서버로 전송하지 않습니다. 유튜브 플레이어와 Google Fonts는 외부 네트워크를 사용합니다.

## 사용 순서

1. 표현 추가로 직접 문장을 입력하거나 내 표현 수집함 → 자막 불러오기에서 이용 권한이 있는 파일을 선택합니다.
2. 뜻과 문맥 메모를 작성합니다. 필요하면 유튜브 링크와 시작 시간을 입력합니다.
3. 저장된 카드를 열고 녹음 시작 → 종료 → 미리 듣기 → 녹음 저장을 누릅니다.
4. 다음 날 오늘의 복습에서 빈칸 퀴즈를 확인하고 복습 완료를 누릅니다.
5. 데이터 관리에서 전체 백업하거나 녹음 보관함에서 파일을 개별 다운로드합니다.

## 시제품 범위

AI 해설 API, 음성 인식 비교, 정밀 발음 평가, 푸시 알림, 계정·서버 동기화, 유튜브 자막 자동 추출은 구현하지 않았습니다. 학습 메모는 사용자가 작성합니다. 카드의 전체 문장은 언제든 확인할 수 있으며 퀴즈는 자기 확인 방식입니다. 오답이어도 정답 확인 후 복습을 완료할 수 있습니다. 3일 복습 완료는 숙련도를 보장하지 않습니다.

영상의 임베드 허용 여부에 따라 재생이 제한될 수 있습니다. 영상 자체나 유튜브 자막을 다운로드하지 않습니다. 자막·표현 이용 권한은 사용자가 확보해야 합니다.

## 검증

```sh
npm run check
npm test
```

날짜 경계, 복습 중복 방지와 완료, 유튜브 URL 검증, SRT/VTT 파싱을 테스트합니다. 실제 기기에서 마이크 권한·녹음·저장 후 새로고침·백업 복원·카드와 녹음 삭제를 추가 확인해야 합니다.

## 구조

- `index.html`: 앱 레이아웃 및 편집 다이얼로그
- `src/style.css`: 반응형 화면
- `src/app.js`: IndexedDB, 카드·녹음·백업과 화면 흐름
- `src/core.js`: 날짜·복습·자막·URL 순수 함수
- `server.mjs`: 의존성 없는 로컬 정적 서버
- `tests/core.test.js`: 핵심 로직 테스트

## 배포

HTML/CSS/JavaScript 정적 앱이므로 GitHub Pages에서도 실행 가능합니다. 저장소 Settings → Pages → Deploy from a branch → main / root를 선택하면 됩니다. 최초 공개 여부 및 Pages 사용 가능 여부는 저장소 설정과 요금제에 따릅니다. 사이트 원본이 공개되더라도 학습 데이터는 해당 브라우저에만 저장됩니다. 이 작업에서 Pages 활성화나 공개 배포는 하지 않았습니다.
