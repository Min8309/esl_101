# 아이폰 문장 알림 설정

아이폰 11은 iOS 16.4 이상이면 홈 화면 웹 앱의 푸시 알림을 사용할 수 있습니다. 설정 → 일반 → 정보 → iOS 버전에서 확인하세요.

## 1. Render 서버 준비 (최초 1회)

아래 설정 전에도 기존 말줍·Google Sheets 기능은 계속 사용할 수 있습니다. 알림 서버만 비활성화됩니다.

1. GitHub 최신 main을 배포합니다. Docker 런타임/Node 24를 사용합니다.
2. Render 서비스 **Settings → Instance Type**에서 유휴 정지되지 않는 인스턴스를 선택합니다. 계속 실행되는 서비스와 Disk에는 비용이 발생할 수 있으니 Render의 현재 요금을 확인하세요. 이 코드 추가가 유료 자원을 자동 생성하지는 않습니다.
3. **Disks → Add Disk**에서 Mount Path를 `/var/data`로 지정합니다. 용량은 현재 제공되는 최소 용량으로 시작할 수 있습니다. 서비스는 단일 인스턴스로 운영합니다. Disk는 같은 서비스의 재배포·재시작 후에도 예약을 보관합니다. 환경 변수만 설정하고 Disk를 연결하지 않으면 재배포 시 자료가 사라집니다.
4. 개인 PC의 최신 프로젝트 폴더에서 `npm ci` 후 `npm run push:keys`를 실행합니다. Node 24를 권장합니다. 출력된 공개 키와 비밀 키는 한 쌍이며 비밀 키를 채팅·GitHub에 올리지 마세요. 키는 최초 한 번 만들고 유지합니다.
5. Render **Environment**에 아래 4개 변수를 등록합니다. 기존 Google·Supadata 설정은 유지합니다.

   | Key | Value |
   | --- | --- |
   | `VAPID_PUBLIC_KEY` | 생성한 공개 키 |
   | `VAPID_PRIVATE_KEY` | 생성한 비밀 키 |
   | `VAPID_SUBJECT` | `mailto:본인의실제이메일주소` |
   | `PUSH_DATA_DIR` | `/var/data` |

6. 저장·재배포 후 Live인지 확인합니다. `/api/push/config`에서 `enabled:true`가 나와야 합니다. 공개 키만 반환하며 비밀 키는 반환하지 않습니다. `enabled:false`이면 Logs의 `[push]` 안내와 쓰기 가능한 Disk 경로를 확인하세요.

유휴 정지되는 무료 서버는 앱을 닫은 동안 예약 시각에 실행되지 않을 수 있습니다. 정시 알림에는 상시 실행이 필요합니다. 서버는 30초마다 기한이 된 예약을 확인하며 APNs·인터넷·집중 모드에 따라 추가 지연이 있을 수 있습니다. 기본 시계 앱 알람과 같은 강제 소리는 지원하지 않습니다.

## 2. 아이폰 홈 화면에 추가

1. 아이폰 **Safari**에서 `https://esl-101.onrender.com/`을 엽니다. 카카오톡·네이버 등의 앱 내부 브라우저 대신 Safari를 사용하세요.
2. 공유 버튼 **□↑**을 누릅니다. Safari 버전에 따라 하단 또는 메뉴 안에 있습니다.
3. 공유 목록을 아래로 내려 **홈 화면에 추가**를 누릅니다. 항목이 보이지 않으면 목록 하단의 동작 편집을 확인하세요.
4. 이름을 **말줍**으로 두고 **추가**를 누릅니다. ‘웹 앱으로 열기’가 표시되면 켜세요.
5. 홈 화면의 **말줍 아이콘**으로 실행합니다. Safari 탭에서 권한을 요청하는 것과 다릅니다.

## 3. 아이폰과 PC 연결

1. 홈 화면의 말줍 → 메뉴 → **데이터 관리 → 아이폰 문장 알림**으로 갑니다.
2. **새 연결 키 만들기** → **이 기기 알림 켜기** → iOS 창에서 **허용**을 누릅니다.
3. **테스트 알림 보내기**를 누르고 잠금 화면 또는 알림 센터에서 수신을 확인합니다. ‘전송 요청 완료’는 기기 화면 표시까지 확인한 뜻은 아닙니다.
4. PC에서도 예약하려면 **연결 키 복사**로 같은 키를 PC 말줍의 데이터 관리에 입력한 뒤 **입력한 키 적용**을 누릅니다. PC 자체의 알림은 켜지 않아도 됩니다. 키는 비밀번호처럼 취급하고 본인의 안전한 전송 경로·비밀번호 관리자를 사용하세요. 키가 있으면 해당 그룹의 문장 조회·예약·삭제가 가능합니다. Google 로그인과 별도의 연결입니다.
5. PC 또는 아이폰에서 **내 표현 수집함 → 카드 열기 → 휴대폰으로 문장 알림 → 날짜·시간 선택 → 이 문장 알림 예약**을 누릅니다. 최초 검증은 1~2분 뒤로 예약하세요. 입력 시간은 예약하는 기기의 시간대이며 서버에는 UTC로 저장합니다.
6. 아이폰에서 알림을 누르면 문장과 학습 메모가 열리고 휴대폰 수집함에도 저장됩니다. 기존 전체 수집함·녹음·복습 기록이 자동 동기화되는 것은 아닙니다. 1일·3일·7일 뒤 알림을 원하면 각각 날짜로 예약하세요. 현재는 한 번씩 보내는 예약입니다.

## 4. 확인·해제·보안

- **예약 확인**에서 연결 기기 수, 예약 시각, 예약됨/전송됨/실패 등을 확인하고 예약을 취소합니다. 전송됨은 푸시 제공자가 요청을 수락했다는 의미입니다.
- **이 기기 알림 끄기**는 현재 기기만 해제합니다. **연결된 모든 기기·예약 삭제**는 같은 연결 키에 속한 서버 자료를 삭제합니다. 기존 연결 키는 다른 기기의 입력란에도 남으므로 유출된 경우 모든 기기의 키를 새로 만드세요.
- iOS 설정 → 알림 → 말줍에서 알림 권한과 미리보기, 집중 모드의 허용 앱을 확인하세요. 잠금 화면에 문장 일부가 표시될 수 있습니다.
- 예약한 문장·뜻·학습 메모 사본, 예약 시각, 알림 구독 정보가 Render Disk에 저장됩니다. Google 토큰·녹음·날짜별 암기 메모 전체를 업로드하지 않습니다. 웹 푸시 전송 내용은 표준 Web Push 방식으로 암호화합니다. 서버 DB 자체에 앱 차원의 암호화는 없으므로 운영자·호스팅 계정 접근 권한을 보호하세요.
- 연결 키는 브라우저 localStorage, 서버에는 키의 SHA-256 해시만 저장합니다. 기기 백업·브라우저 자료 삭제 후에는 키를 다시 입력해야 합니다. 앱 JSON 백업에는 알림 연결 키와 서버 예약이 포함되지 않습니다.
- 알림 기록은 완료·실패 후 약 30일, 구독은 등록 후 180일이 지나면 정리됩니다. 180일 전이라도 기기 알림을 다시 켜면 구독을 갱신할 수 있습니다. 24시간 이상 지난 미전송 예약은 만료 처리합니다. 일시 오류는 최대 3번 시도합니다. 서버가 전송 직후 중단되면 재시도 과정에서 중복 수신할 수 있습니다.
- Disk의 SQLite 파일은 개인 자료입니다. 백업·접근 권한을 관리하고 공개 경로로 제공하지 마세요. 저장 공간이 있는 단일 인스턴스용이며 여러 서버로 확장하려면 공유 DB·전용 작업자를 별도 구성해야 합니다.
